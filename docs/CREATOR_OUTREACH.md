# Creator Permission & Outreach Tracker / Controle de Pedidos de Permissão aos Criadores

This file tracks creator permissions for every community mod/translation compatibility slot listed in [`mods/registry.json`](../mods/registry.json) and provides ready-to-send outreach messages.

> **Policy:** Zero third-party mod or translation files are ever bundled, redistributed, or auto-downloaded without explicit written permission. All slots below are strictly `manual_import: true` (direct link to the creator's official page + local `.xdelta`/`.ips`/`.dospatch` import by the player).
